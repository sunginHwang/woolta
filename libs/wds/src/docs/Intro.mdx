# WDS — Woolta Design System

Woolta 서비스(blog · woolbank · woolta)가 공유하는 디자인 시스템입니다.
특정 도메인에 의존하지 않는 **토큰과 컴포넌트만** 이곳에 둡니다.

## 구조

사이드바는 추상화 단계 순서로 읽습니다. 토스 TDS·당근 SEED·Polaris 가 공통으로 쓰는
**Foundations → Components → Utilities** 3층 구조입니다.

| 섹션 | 내용 | 소스 |
| --- | --- | --- |
| **Foundations** | 색상·타이포그래피·그림자·z-index 토큰. 모든 컴포넌트의 재료 | `src/lib/style/` |
| **Components** | 화면에 그려지는 UI. 디자인 시안과 1:1 로 대응 | `src/lib/atom/`, `src/lib/common/` |
| **Utilities** | 화면을 그리지 않는 도우미(Portal, Suspense). 동작만 설명 | `src/lib/atom/`, `src/lib/common/` |

### 토큰 계층

TDS 와 같은 2단계(Base → Semantic) 체계입니다.

- **Base** `palette.gray[800]` — 색 값 자체. 컴포넌트에서 직접 쓰지 않습니다.
- **Semantic** `colorVars['--color-textPrimary']` — 역할(text / bg / border / interactive / brand / status).
  컴포넌트는 이 층만 참조합니다. 다크 테마는 `darkTheme.css` 가 같은 변수를 재정의하므로 컴포넌트 코드는 테마를 모릅니다.

## 컴포넌트 카탈로그

woolbank 에서 쓰던 구현을 당근 SEED·토스 TDS 의 옵션 체계와 합쳐 공용화한 것들입니다.

| 묶음 | 컴포넌트 | woolbank 원본 |
| --- | --- | --- |
| 액션 | Button, FloatingActionButton, Chip(+ChipGroup), Toggle | Button, AddButton, 통계 필터 알약, Toggle |
| 폼 | TextInput, Textarea, Select, Checkbox, Radio(+RadioGroup) | BaseInput/FormInput (나머지는 신규) |
| 내비게이션 | Tabs, SegmentedControl, BottomNavigation, Header(+Sub), DropdownTitle | Tabs/ToggleTab, AccountBookTabs, NavigationBar, Header/SubHeader, DropdownTitle |
| 오버레이 | Overlay, BottomSheet(+Menu), Toast, Confirm, FullScreenLoading | Deem, DefaultBottomSheet/MenuSheet, Toast, Confirm, FullScreenLoading |
| 피드백·상태 | Badge, Tag, Progress, Spinner, EmptyState, Skeleton(+SkeletonBar) | 알림 배지, '정기이체' 라벨, Progress, ClipLoader, EmptyInfo, *Skeleton |
| 레이아웃 | Stack, Card, Text | monolith Stack, CardItem, Text |
| 목록 | ListRow, ListSectionHeader | 가계부 Item/DayGroup, 마이페이지 설정 행 (신규) |
| 일정 | Timeline | 정기지출 이체 일정 (신규) |
| 아이콘 | `Icon*` 34종 (Foundations/Icons) — Bell·Settings·Clock·InfoCircle·Theme·ChartOutline 추가 | components/atom/Icon |

공통 규칙: Next·motion·jotai·`@common` 에 의존하지 않습니다. 라우팅은 `linkComponent`·`onBackClick` 같은 prop 으로,
스크롤 방향·전역 상태는 호출하는 쪽이 넘깁니다.

## 컴포넌트 문서 읽는 법

각 컴포넌트의 **Docs** 탭은 자동 생성되며 다음 순서로 구성됩니다.

1. **설명** — 컴포넌트 JSDoc. 언제 쓰는지, 무엇을 하지 않는지
2. **Primary 예시 + Controls** — props 를 직접 바꿔 보며 확인
3. **Stories** — 상태(기본 / 선택됨 / 비활성 / 로딩 …)별 고정 예시
4. **접근성** — 스토리에 a11y 애드온 결과가 붙습니다 (하단 Accessibility 탭)

툴바의 **Theme** 로 라이트/다크를 전환하면 앱과 같은 `html[data-theme]` 방식으로 반영됩니다.

## 컴포넌트 추가 규칙

```
src/lib/atom/ComponentName/
├── index.tsx            # 'use client' + stylex.create 를 모듈 상단에
└── index.stories.tsx    # title: 'Components/ComponentName'
```

- props 는 **JSDoc 으로 설명**합니다. 그 주석이 Docs 의 Controls 표에 그대로 노출됩니다.
- 색은 `colorVars`, 글꼴은 `typographyStyles`, 층은 `zIndexConsts` 만 씁니다. hex 리터럴 금지.
- 외부 확장은 `xstyle?: StyleXStyles` 한 가지 통로로 받고, 항상 마지막에 머지합니다.
- 스토리는 최소 **기본 / 각 상태 / 라벨 없는 경우(aria-label)** 를 만듭니다. 스토리는 Vitest 브라우저 테스트로도 실행됩니다.

## 실행

```bash
pnpm turbo run storybook --filter=@woolta/wds   # http://localhost:4600
```
