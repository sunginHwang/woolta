# Icons

woolbank 에 흩어져 있던 아이콘(앱 24개 + 라이브러리 복사본)을 `@wds` 한 곳으로 모았습니다.
모든 아이콘은 `createIcon` 으로 만들어져 같은 props 를 받습니다.

| prop | 설명 | 기본값 |
| --- | --- | --- |
| `size` | 한 변의 길이. 숫자는 px | `24` |
| `color` | 채움색. 기본은 글자색(`currentColor`)을 따른다 | `'currentColor'` |
| `title` | 접근성 이름. 주면 `role="img"` + `<title>`, 없으면 장식용(`aria-hidden`) | - |
| `xstyle` | StyleX 오버라이드 | - |

이름은 woolbank 의 import 이름(`IconChevronLeft`)을 그대로 유지했으므로 경로만 `@wds` 로 바꾸면 됩니다.
`IconGoogle`·`IconKakaoTalk` 은 브랜드 고정색이라 `color` 를 무시합니다.

## 색

기본은 부모의 글자색을 따르므로 `Text` 의 `color` 와 함께 바뀝니다. 직접 줄 때는 Semantic 토큰 값을 넘깁니다.

<Unstyled><IconColorRow /></Unstyled>

## 하단 내비게이션용 Outline / Fill 짝

당근 SEED 는 하단 탭 아이콘을 Fill 스타일로 통일하고 활성 여부를 톤으로만 구분합니다.
wds 는 `IconPigFill` · `IconWalletFill` · `IconChartFill` · `IconAccountFill` 을 추가했고, `NAVIGATION_ICON_PAIRS` 로 짝을 제공합니다.
Outline 과 Fill 을 한 바에 섞지 않습니다.

## 사용

```tsx
import { IconChevronLeft, IconPlus } from '@wds';

<button type='button' aria-label='뒤로'>
  <IconChevronLeft size={20} />
</button>

<IconPlus title='추가' color={colorVars['--color-interactivePrimary']} />
```
