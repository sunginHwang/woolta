# Colors

색상 토큰은 두 층입니다. 컴포넌트는 **Semantic 층만** 참조합니다.

| 층 | 어디에 | 예시 | 쓰는 곳 |
| --- | --- | --- | --- |
| Base | `palette.ts` | `palette.pink[600]` | Semantic 토큰 정의, 문서 |
| Semantic | `tokens.stylex.ts` → `colorVars` | `colorVars['--color-brandPrimary']` | 모든 컴포넌트 |

다크 테마는 `colors/darkTheme.css` 가 `:root[data-theme="dark"]` 에서 같은 CSS 변수를 재정의합니다.
StyleX `defineVars` 의 키를 `--color-*` 리터럴로 두었기 때문에, CSS Module 에서도 `var(--color-textPrimary)` 로 같은 토큰을 읽을 수 있습니다.
